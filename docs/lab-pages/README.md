# Lab Page Drafts

These files are reader-facing Lab page drafts for the Unfurl Systems site.

They sit between the DCP Journey blog pages and the repository technical docs:

- The blog pages explain why the idea matters.
- The Lab pages explain what currently exists and how to inspect it.
- The repository docs remain the source of truth for implementation details.

## Editorial Rule

Do not let these pages become a second technical specification. Each page should
summarize, route, and explain. If a reader needs exact schema, API, or build
behavior, send them to the source docs in the relevant repository.
